2. RequireHttpsMetadata = false — OIDC discovery over HTTP

4. DB passwords (123456) in git-tracked appsettings.json
5. ShowPII = true unconditional — logs full tokens/emails

**HIGH (4):**
1. Tenant spoofing — middleware before auth, X-Tenant unvalidated
2. 36 endpoints missing Permissions(), 2 incorrectly AllowAnonymous (UpdateUser!)
3. Debug endpoints accessible in production (ComboBreakTest, DecodeAudit)
4. All JWT claims logged at Information level (PII every request)

**MEDIUM (5):**
1. Pipeline key normalization (PortalDb vs System)
2. Health endpoints expose infra details
3. AppException messages always returned to client
4. Debug-level auth logging in base appsettings
5. GetProjectAssignments duplicate route bug
