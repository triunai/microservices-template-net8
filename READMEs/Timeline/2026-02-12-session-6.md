### SSO 401 Bug — RESOLVED

**Symptom:** SSO broker mints tokens OK, OIDC discovery reachable, portal API returns 401 on all SSO requests.

**Debugging steps (chronological):**

1. **Silent logger fix** — `OnAuthenticationFailed` used `LogDebug` on `ILogger<Program>`, but Serilog `Default: Information` filtered it. Changed to `LogWarning`. Also fixed `OnTokenValidated` from `LogDebug` to `LogInformation`.

2. **Serilog bootstrap fix** — Early bootstrap only loaded `appsettings.json`, not `appsettings.Development.json`. So `Microsoft.AspNetCore.Authentication: Debug` override was never loaded. Fixed to include `appsettings.{environment}.json`.

3. **Error revealed** — `IDX10500: Signature validation failed. No security keys were provided to validate the signature.`

4. **SSL backchannel hypothesis** — Added `BackchannelHttpHandler` with `DangerousAcceptAnyServerCertificateValidator` (dev only). Did NOT fix it. But kept as standard ASP.NET pattern.

5. **PowerShell verification** — OIDC discovery (`200 OK`) and JWKS (`200 OK`, valid RSA key) both reachable from same machine. SSL cert trusted.

6. **ConfigurationManager diagnostic** — Added diagnostic to `OnAuthenticationFailed` that inspected the ConfigurationManager's state. Revealed: `Issuer: https://localhost:7012, SigningKeys: 0, JwksUri: null`. Manual fetch from within the API process succeeded — the JSON was valid.

7. **ROOT CAUSE FOUND** — Package version mismatch:
   - `Microsoft.IdentityModel.Protocols.OpenIdConnect` = **7.1.2** (transitive from `JwtBearer 8.0.11`)
   - `Microsoft.IdentityModel.Tokens` = **8.8.0**
   - The 7.1.2 parser extracted `issuer` but failed to extract `jwks_uri` from valid OIDC discovery JSON.

8. **Fix** — Pinned `Microsoft.IdentityModel.Protocols.OpenIdConnect` and `Microsoft.IdentityModel.Protocols` to `8.8.0` in API csproj. SSO login immediately worked.

9. **Cleanup** — Removed diagnostic code from `OnAuthenticationFailed`, kept permanent fixes.

## Key Learnings
1. **NuGet transitive version splits can cause silent parsing failures** — `JwtBearer 8.0.11` pulls `Protocols.OpenIdConnect 7.1.2` but other packages bring in `Tokens 8.8.0`. The mismatch causes OIDC discovery parsing to silently lose fields.
2. **Always check transitive package versions** when debugging auth issues — `dotnet list package --include-transitive`.
3. **Serilog early bootstrap must include env-specific config** — otherwise Development overrides are never loaded.
4. **Auth failures should ALWAYS log at Warning** — Debug is too aggressive a filter for auth failures.
